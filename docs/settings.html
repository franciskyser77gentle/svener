GitHub access

Use a fine-grained token scoped only to this repository. It stays in this browser: localStorage when remembered, or sessionStorage otherwise.

  1. Open GitHub's token creator.
  2. Choose Fine-grained tokens, set this repository only, and choose an expiration.
  3. Under Repository permissions select Contents: Read and write, Secrets: Read and write, and Actions: Read and write.
  4. Generate the token and paste it below. GitHub shows it only once.

Update TaoStats API key

The key is sealed in this page with libsodium and sent only to GitHub's Actions secret API. It is never displayed, logged, or stored by this page.
